Cloud Resume Challenge

Project information

  • Category: Serverless architecture
  • Source code: View on GitHub
  • Live site: resume.gocloud.com.ng
  • Built: March - April 2024

What it is: A resume site that counts every visit and deploys itself. The page you are reading is the result.

How it works: The visitor counter runs on API Gateway, Lambda, and DynamoDB. The frontend is served from S3 through CloudFront on a Route 53 domain. GitHub Actions deploys both the stack and the site using OIDC, so no long-lived AWS keys are stored. Cypress checks the live site after each deploy.
